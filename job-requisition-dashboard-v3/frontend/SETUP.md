# Frontend Setup Instructions

## Prerequisites
- Node.js 18+ and npm

## Installation Steps

1. **Install dependencies**:
   ```bash
   cd frontend
   npm install
   ```

2. **Install additional package for Tailwind animations**:
   ```bash
   npm install tailwindcss-animate
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   The app will be available at http://localhost:3000

4. **Build for production**:
   ```bash
   npm run build
   ```

## What's Included

- ✅ React 18 with TypeScript 5
- ✅ Vite 5 for fast builds
- ✅ Tailwind CSS 3 with Taylor Morrison brand colors
- ✅ ShadCN/ui components (Button, Card, Table, Badge, Select)
- ✅ Recharts for data visualization
- ✅ React Query for data fetching
- ✅ React Router for navigation
- ✅ Axios for API calls

## Next Steps

Once dependencies are installed, the frontend is ready for component development (Phase 3).
