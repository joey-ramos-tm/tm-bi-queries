# Lead Source Analysis

Comprehensive analysis of lead sources to determine effectiveness in generating appointments and sales.

## Project Overview

This project tracks customer journeys from first lead source through appointments to final sale, calculating key metrics:

- **First Lead Source**: Identifies the initial marketing touchpoint for each contact
- **Days to First Appointment**: Time from lead source to first scheduled appointment
- **Days to Sale**: Time from first appointment to closed sale
- **Conversion Rates**: Lead → Appointment → Sale conversion percentages

## Business Questions Answered

1. Which lead sources produce the most appointments?
2. Which lead sources produce the most sales?
3. What is the average time from lead source to appointment?
4. What is the average time from appointment to sale?
5. Which lead sources have the highest conversion rates?
6. What is the revenue generated by each lead source?

## Data Sources

### Tables Used

1. **Lead Source**: `[TaylorMorrisonDWH_Silver].[SLS_MKT_VW].[LEAD_SRC]`
   - Contact ID
   - Lead Source ID, Name, Type
   - Created Date

2. **Appointments**: `[TaylorMorrisonDWH_Silver].[SILVER_DB].[EVENT]`
   - Contact ID
   - Event ID, Date, Type
   - Filtered by: `APP_TYPE_HANDLE_CD = 'APP_TYPE_HANDLE_CD'`

3. **Sales**: `[TaylorMorrisonDWH_Silver].[SILVER_DB].[SALE]` *(Update with actual table)*
   - Contact ID
   - Sale ID, Date, Amount

## SQL Files

### 1. lead_source_analysis.sql
**Purpose**: Aggregated metrics by lead source
**Output**: Summary statistics showing performance of each lead source

**Key Metrics**:
- Total Contacts
- Total Appointments
- Total Sales
- Appointment Conversion Rate (%)
- Sale Conversion Rate (%)
- Average Days to First Appointment
- Average Days Appointment to Sale
- Total Revenue
- Average Sale Amount

**Use Case**: Executive dashboard, lead source ROI analysis

### 2. lead_source_detail.sql
**Purpose**: Individual contact-level journey data
**Output**: One row per contact showing their complete journey

**Columns**:
- Contact ID
- Lead Source Details
- First Appointment Date
- First Sale Date
- Days Calculations
- Journey Stage Classification

**Use Case**: Detailed analysis, data validation, export to Excel

## Optimization Features

### Performance Optimizations
1. **CTEs with ROW_NUMBER()**: Efficiently identifies first occurrence of lead source, appointment, and sale
2. **Early NULL Filtering**: Reduces dataset size before joins
3. **Appropriate JOIN Types**: LEFT JOINs preserve lead source data
4. **Post-Aggregation Filtering**: HAVING clause applied after GROUP BY

### Recommended Indexes
```sql
CREATE INDEX idx_lead_src_contact_created
    ON [TaylorMorrisonDWH_Silver].[SLS_MKT_VW].[LEAD_SRC]
    (CONTACT_ID, CREATED_DATE);

CREATE INDEX idx_event_contact_date
    ON [TaylorMorrisonDWH_Silver].[SILVER_DB].[EVENT]
    (CONTACT_ID, EVENT_DATE)
    WHERE APP_TYPE_HANDLE_CD = 'APP_TYPE_HANDLE_CD';

CREATE INDEX idx_sale_contact_date
    ON [TaylorMorrisonDWH_Silver].[SILVER_DB].[SALE]
    (CONTACT_ID, SALE_DATE);
```
